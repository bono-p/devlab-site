# DevLab Africa — Site officiel (V2)

Site institutionnel de DevLab Africa. Front-end statique (HTML/CSS/JS vanilla, sans framework ni build) — prêt à déployer tel quel sur Render en site statique.

## Structure

- `index.html` — Home
- `projects/` — pages projet (gabarit : `calvonote.html`)
- `css/` — `tokens.css` (couleurs/typo), `components.css` (nav, cartes, statuts...), `home.css`, `project.css`
- `js/main.js` — thème clair/sombre, nav mobile, cookie consent, points d'intégration backend

## Backend (à venir)

Le front est fonctionnel seul, sans backend. Les emplacements prévus pour Supabase (newsletter, contact, cookies/analytics, auth) sont marqués `// TODO backend:` dans `js/main.js`.
